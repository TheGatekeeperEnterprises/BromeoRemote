Voer een wachtwoord in

Schakelt je fysieke beeldscherm uit zodra iemand verbindt en bestuurt — voorkomt meekijken door iemand naast je. Schermdeling zelf blijft gewoon werken. Blokkeert geen lokale muis/toetsenbord: die wekken het scherm weer.

Weiger inkomende verbindingen van BromeoRemote-ID's die niet bij je opgeslagen apparaten staan. Handig voor vaste werkplekken en onbeheerde toegang.

Extra beveiliging bovenop onbeheerde toegang: naast het vaste wachtwoord is ook een 6-cijferige code uit je authenticator-app (Google Authenticator, Authy, …) nodig.

Voeg deze sleutel handmatig toe in je authenticator-app als "BromeoRemote", en bevestig daarna met de code die de app toont:

2FA is ingeschakeld voor onbeheerde toegang.

Laat iemand die dit apparaat bestuurt Ctrl+Alt+Del versturen (bv. om een vergrendeld scherm te ontgrendelen). Windows staat dit normaal niet toe voor gewone apps — dit registreert een SYSTEM-taak in Taakplanner die alleen op aanvraag draait (nooit bij opstarten), plus de bijbehorende beveiligingsinstelling. Vereist eenmalig een beheerdersbevestiging (UAC). Experimenteel: op een echte Windows 11-machine registreert dit correct, maar het daadwerkelijke Ctrl+Alt+Del-scherm verscheen niet — mogelijk werkt dit mechanisme niet (meer) op recente Windows-versies.
