Voor wie

Remote support zonder gedoe

IT-support

Neem veilig sessies over, wissel monitoren, synchroniseer klembord en verstuur bestanden tijdens dezelfde verbinding.

Onderweg

Gebruik de mobiele app als viewer met touch- en muismodus, chat en snelle sessieacties.

Onbeheerde toegang

Laat vertrouwde apparaten verbinden met vaste wachtwoorden, 2FA en duidelijke sessiemeldingen.

Eigen beheer

Draai signaling, updates, website, database en mail op je eigen server via Coolify.

Veiligheid

Gebouwd met controle aan jouw kant

De website verzamelt alleen wat nodig is voor downloads en contact. De remote sessies lopen via WebRTC-versleuteling; de server koppelt apparaten maar ziet geen scherminhoud.

  • Session ID + wachtwoord, view-only en rechten per sessie.
  • Host ziet altijd dat er iemand verbonden is en kan direct verbreken.
  • PostgreSQL logging voor contactaanvragen, nieuwsbrief en downloadstatistiek.
  • SMTP via je eigen domeinmail, ingesteld als Coolify secret.
