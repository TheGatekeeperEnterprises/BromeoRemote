Eigen infrastructuur

Klaar voor Coolify, PostgreSQL en je eigen maildomein.

BromeoRemote is opgezet zodat de publieke website, database, SMTP en downloadlinks op je eigen server kunnen draaien. Zo houd je branding en operationele controle in eigen hand.

Website Dockerfile, healthcheck en omgevingvariabelen voor Coolify.
Database PostgreSQL opslag voor contact, releaselijst en downloadregistratie.
Downloads Windows installer, portable build en Android APK via eigen downloadlinks.
Mail SMTP via info@bromeoremote.com voor contactaanvragen en opvolging.

Veiligheid

Controle voor de host, vertrouwen voor de gebruiker.

Remote support moet zichtbaar, begrijpelijk en afsluitbaar zijn. Daarom krijgt de host duidelijke sessiemeldingen, rechten per verbinding en directe noodknoppen.

  • Per sessie rechten Muis, toetsenbord, klembord en bestanden kunnen apart worden toegestaan.
  • Altijd zichtbare melding De host ziet wie verbonden is en kan de sessie direct stoppen.
  • Onbeheerd met extra beveiliging Vast wachtwoord, vertrouwde apparaten en 2FA voor beheer op afstand.
  • Eigen dataflow Je beheert website, database, mail en signaling via je eigen infrastructuur.

FAQ

Veelgestelde vragen.

Is BromeoRemote bedoeld als TeamViewer-alternatief?

Ja. De focus ligt op remote support, meekijken, besturen, chatten en bestanden overzetten, maar met eigen hosting en branding.

Kan ik de server zelf beheren?

Ja. De website is voorbereid voor Coolify. De signaling server en downloads kunnen ook via eigen subdomeinen worden aangeboden.

Waar worden contactaanvragen opgeslagen?

In PostgreSQL. De website stuurt daarnaast een mail via de ingestelde SMTP-server, zonder wachtwoorden in de code op te slaan.

Zijn de downloadknoppen direct actief?

Ja zodra de download-URL's in Coolify zijn ingesteld. Tot die tijd verwijzen ze netjes naar contact.
